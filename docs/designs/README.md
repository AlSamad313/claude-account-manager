# Design history

These files record how the project was planned, and are kept for background. **The code and [ARCHITECTURE.md](../ARCHITECTURE.md) are the current truth.** Where they differ from these files, trust the code.

- `claude-profile-manager.md`: the design document. Its rules still explain why the code works as it does.
- `concept_input.md`, `concepts_brief.md`: the original idea and brainstorm.
- The `*_report*.md` files: reviews of the design, written before the code existed. Their findings aren't a list of open bugs.
